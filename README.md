# TIGER KHAN PKD Termux Logo

Upload install.sh and uninstall.sh to a public GitHub repository.

Install command (replace USER and REPO):
```bash
curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/install.sh | bash
```

Uninstall command:
```bash
curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/uninstall.sh | bash
```

The installer only adds the welcome logo to Termux ~/.bashrc and installs
figlet, toilet, ruby, and lolcat. Run scripts only from sources you trust.
